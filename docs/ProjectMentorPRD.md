# ProjectMentor项目需求&产品逻辑

## 一、项目背景与创作初衷

本人作为大厂实习生，深刻体会到**校园理论学习与企业实战学习的巨大差距**：看书、刷题、背知识点的学习方式碎片化、易遗忘、无法落地；而在企业真实业务项目中，通过实战上手的技术、业务逻辑，记忆深刻、可复用、真正能转化为个人工程能力，也是互联网求职、秋招最核心的竞争力。

学习痛点：

1. 想学新技术，但不知道练什么项目、没有科学的学习路径；

2. 盲目自学，学完只会概念，面试无项目可讲；

3. 缺少导师督促、缺少 DDL 约束，学习拖延、半途而废；

4. 学完不会复盘输出，无法形成知识闭环，达不到真正掌握的效果。

因此，我设计并开发**PBL（Project Based Learning） 项目制 AI 导师 Agent**，摒弃苦闷的问答式 AI 学习工具，复刻企业真实带教逻辑，打造对标职场实习的沉浸式实战学习 Agent。

## 二、项目核心整体流程

用户输入**想要学习的技术 / 知识领域**后，AI 导师 Agent 启动完整学习流程：**智能检索Github开源项目 → 择优推荐排序 → 自定义项目生成 → 任务拆解 \+ DDL 布置 → 过程知识点答疑 → 费曼复盘输出**，全程模拟职场导师带教模式，实现「输入 \- 实战 \- 答疑 \- 输出」完整学习闭环。

## 三、详细核心功能需求

### 1\. GitHub 开源项目智能检索 \& 推荐模块（核心特色差异化功能）

用户确定学习方向后，Agent**优先自动检索 GitHub 对应领域优质开源实战项目**，而非直接自创任务，贴合开发者真实学习习惯：

1. 自动筛选高 Star、文档完善、新手友好、工程规范的实战项目；

2. 按照**入门 / 初级 / 中级**做难度梯度排行榜；

3. 自动生成每一个项目的详细推荐理由、适配人群、可学到的核心技术点、练习侧重点、需要规避的学习误区；

4. 给到用户自主选择权：

    - 若用户认可现有开源项目：直接基于 GitHub 项目开展实战学习，Agent 全程跟进带教；

    - 若 GitHub 无适配的小众学习方向、或用户不想复用现有项目、希望从零实战：Agent**为用户量身定制专属个性化实战项目任务**。

### 2\. 项目拆解 \+ 职场化 DDL 任务布置

无论用户选择开源项目学习 or 定制新项目学习，Agent 会模拟企业导师：

1. 将整体项目拆解为阶段性小任务；

2. 为每阶段任务设置合理 DDL 截止日期；

3. 明确每一步需要掌握的知识点、交付标准，复刻真实实习项目开发节奏。

### 3\. 双窗口隔离式交互答疑系统（产品体验核心优化）

为解决单窗口对话混乱、任务记录被答疑消息冲刷的问题，产品采用**双窗口独立布局**：

1. **主任务窗口**：仅用于展示整体项目任务、阶段要求、DDL 进度、任务更新，全程干净整洁，留存完整学习任务链路；

2. **独立答疑子窗口**：用户开发、学习过程中遇到的所有技术问题、知识点疑问，在专属答疑窗口提问；

3. 答疑窗口**自动绑定当前正在进行的项目知识背景**，Agent 会基于用户当下的学习项目、技术栈精准答疑，不会脱离学习场景泛泛回答，实现场景化精准辅导。

### 4\. 个性化费曼学习法复盘输出模块

用户完成全部项目实战任务后，Agent 不会简单结束学习流程，而是复刻职场汇报逻辑，完成知识固化闭环：

1. Agent 主动询问用户**偏好的复盘汇报形式**，尊重用户学习习惯；

2. 提供多模式职场化复盘选项：PPT 汇报、结构化技术总结文档、口头逻辑复述、项目技术复盘博客等；

3. 引导用户用**费曼学习法**输出：用通俗的语言讲清楚项目原理、技术难点、踩坑经验、知识点总结；

4. Agent 针对用户的输出内容纠错、补全、查漏补缺。
